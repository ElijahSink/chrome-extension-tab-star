2. What should the tab group be called?

$1 inserts the first part in parentheses, $2 the second, and so on. Example: pattern /browse/([A-Z]+-\d+) with title $1 gives a group named ABC-123. Plain text with no $ gives every matching tab the same fixed title.

3. Show a status from the page? (optional)

Full guide
The extension looks at the page, finds one element (for example the "In Progress" badge on a ticket), and adds its text to the group title: ABC-123 becomes ABC-123 - In Progress. It keeps watching, so the title updates when the status changes.
What is a CSS selector and how do I get one?

A CSS selector is the address of an element on a web page, the same thing web developers use to style it. #status-val means "the element with id status-val"; [data-testid="header-state"] means "the element whose data-testid attribute is header-state".

To find one for the status on your page:

  1. On the page, right-click the status text or badge and choose Inspect. Chrome DevTools opens with that element highlighted.
  2. Look at the highlighted line. Prefer an attribute that looks hand-written, such as id="...", data-testid="..." or aria-label="...". Random-looking classes like css-1x9kq2 break on the next release.
  3. If that line has nothing useful, click the parent line just above it and check again.
  4. Write the selector: #the-id, or [data-testid="the-value"], or [aria-label="the-label"].
  5. Paste it below and click Test on Current Tab. The result tells you which element matched and what text it read.

You can list several selectors separated by commas; the first one that finds text wins. Shortcut: in DevTools, right-click the element, then Copy › Copy selector. It works but is often fragile, so simplify it if you can.

If the element contains more words than you want (for example "Pipeline #123 passed"), add a Keep only regex with parentheses around the part to keep, such as #\d+\s+(\S+). The test result shows both the raw text and what was kept.

Each field reads one element. With several fields the values are joined, for example Open · CI passed for a merge request and its pipeline. Keep only is an optional regex: if it has parentheses, only that part is kept, so #\d+\s+(\S+) turns "Pipeline #18395789 passed" into "passed". Label is an optional prefix such as CI.
